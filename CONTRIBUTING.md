# Contributing to clean-utils

Thanks for your interest in contributing!

## Development setup

```bash
npm install
npm run lint
npm test
```

## Guidelines

- Every new function must include JSDoc and full test coverage.
- Keep the package zero-dependency; do not add runtime dependencies.
- Run `npm run lint && npm test` before opening a PR.
- Follow conventional commit messages.

## Reporting issues

Please open a GitHub issue with a minimal reproduction.
